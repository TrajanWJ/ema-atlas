# toomanytools

The absurd-capability media/asset/render/diagram/chart/browser agent workspace.

## purpose
Turn ideas into assets:
- charts
- SVGs
- diagrams
- renders
- browser captures
- video workflows
- polished artifacts

## quickstart
```bash
npm install
npm run doctor
npm run mcp:remotion
npm run mcp:charts
npm run mcp:playwright
npm run mcp:mermaid
```

## folders
- `assets/svg` — source SVGs
- `assets/charts` — generated charts
- `assets/renders` — rendered images
- `assets/videos` — video outputs
- `docs/` — capability notes and setup docs
- `scripts/` — utility scripts

## current constraints
- Blender is not installed yet
- MCP servers are installed locally, but not yet globally registered into OpenClaw as named runtime MCP capabilities
- image generation still depends on whichever model/backend is chosen next
