## Ema.Babysitter Architecture

OTP supervision tree (`one_for_one`), started after PubSub in Application.ex:

```
Ema.Babysitter.Supervisor
├── VisibilityHub     — subscribes to 9 PubSub topics, 100-event ring buffer, category mapping
├── StreamTicker      — 45s configurable tick (reads Ema.Settings), drains hub, posts to #babysitter-stream
└── OrgController     — nudge/redirect via PubSub async, set_channel_topic + create_channel via Discord REST
```

**HTTP API at `/api/babysitter/`:**
- `GET /state` — last 20 events + tick config
- `POST /config` — `{tick_interval_ms: N}` → reconfigure + persist
- `POST /nudge` — `{channel_id, message}` → OrgController
- `POST /tick` — manual immediate tick

**Discord channels:**
- `#babysitter-live` (1489786483970936933) — Right Hand stream of consciousness, primary coordination
- `#babysitter-stream` (1489815817867624578) — auto-tick feed from StreamTicker (every 45s)
