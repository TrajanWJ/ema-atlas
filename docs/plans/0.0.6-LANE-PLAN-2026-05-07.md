## M1 — Contract layer load-bearing
**Goal:** Eliminate the three-parallel-implementations drift; make `packages/contracts` the single live source of truth for events/commands/projections.

### LR1 — JSON-Schema export from `@ema/contracts-ts`
- **Scope:**
  - `packages/contracts-ts/src/codegen.ts` (extend)
  - `packages/contracts-ts/src/generated/schemas.json` (new)
  - `packages/contracts-ts/_smoke.ts` (expand to all 144 kinds)
- **Done when:**
  - `pnpm --filter @ema/contracts-ts build` emits a valid JSON-Schema bundle
  - Smoke test asserts a known event/command/projection round-trips through the schema
  - 144 of 144 event kinds covered
- **Depends on:** none

### LR2 — Codegen Gleam types from `contracts/`
- **Scope:**
  - `packages/contracts-gleam/` (new package)
  - `packages/contracts-gleam/src/codegen.{ts|mjs}` (parser shared with contracts-ts where possible)
  - `apps/daemon/src/ema_daemon/contracts/events.gleam` (generated)
  - `apps/daemon/src/ema_daemon/event_envelope.gleam` (lines 94–225 replaced with import-and-validate)
- **Done when:**
  - `gleam check && gleam test` pass
  - Generated catalog has 144 kinds (matching `contracts/catalog.v0.md`)
  - `event_envelope.gleam` no longer hand-codes the kind list
  - `pnpm check:contracts` extended to fail if generated Gleam drifts from markdown
- **Depends on:** LR1 (shared parser)

### LR3 — Wire `apps/web`, `apps/cli`, `apps/agent-blueprint-grower` through `@ema/contracts-ts`
- **Scope:**
  - `apps/web/src/lib/ipc.ts` (replace local types with imports)
  - `apps/web/src/projections/*.ts` (use `ProjectionOf<…>`)
  - `apps/cli/src/commands/*.ts` (use `CommandOf<…>` / `EventOf<…>`)
  - `apps/agent-blueprint-grower/src/emit.ts` (use generated command types)
  - Add ESLint rule blocking new local definitions of typed event/command/projection shapes in `apps/`
- **Done when:**
  - All three apps build with no local-type duplicates of generated kinds
  - Lint rule blocks reintroduction
  - Smoke test: a new event kind added in `contracts/` shows up automatically in all three apps after codegen
- **Depends on:** LR1

## M2 — Daemon decomposition
**Goal:** Replace the 6,666-LOC IPC god module with bounded, per-domain routers; heal context leakage; unify projection serialization; add migration spine.

### LD1 — Split `ema_shell_ipc.gleam` into per-domain routers
- **Scope:**
  - `apps/daemon/src/ipc/dispatch.gleam` (new, ~200 LOC)
  - `apps/daemon/src/ipc/{hierarchy,blueprint,workspace,execution,content,time,replication}_router.gleam` (new)
  - `apps/daemon/src/ema_shell_ipc/ema_shell_ipc.gleam` (gradually shrink to a thin gateway)
  - `apps/daemon/test/ipc/*_router_test.gleam` (new)
  - **Feature flag:** `EMA_IPC_ROUTERS=1` runs the new path; `=0` runs legacy. Both co-exist for one merge cycle.
- **Done when:**
  - All 25+ command kinds route through a domain router under flag
  - All projection-push paths go through unified encoder (LD3)
  - Legacy code path removable behind a follow-up commit
  - Daemon test suite green; `m1-round-trip.mjs` green; `m2-dispatch-round-trip.mjs` green
- **Depends on:** LR2 (uses generated event types)
- **Risk:** Highest single-lane risk. Do under feature flag.

### LD2 — Heal `ema_orgs ↔ ema_spaces` leakage; wire Elixir contexts to bus
- **Scope:**
  - `apps/daemon/src/ema_orgs/*.gleam` (drop direct `ema_spaces` import; emit `org.created` only)
  - `apps/daemon/src/ema_spaces/*.gleam` (subscribe to `org.created`; emit `space.created`)
  - `apps/daemon/lib/ema_clients/projection.ex` (subscribe to `client.*` events through canonical bus)
  - `apps/daemon/lib/ema_responsibilities/projection.ex` (subscribe to `responsibility.*` events)
  - `apps/daemon/test/ema_orgs_test.gleam` (assert no transitive `ema_spaces` import)
- **Done when:**
  - `ema_orgs` has zero direct module dependency on `ema_spaces`
  - Org-create test still results in default-space creation, but via event chain
  - Elixir context tests demonstrate bus-driven projection rebuild
- **Depends on:** LD1 (cleaner module boundaries)

### LD3 — Unified projection serialization
- **Scope:**
  - `apps/daemon/src/ema_daemon/projection_encoder.gleam` (new)
  - All `ema_*` modules that push projection JSON now go through the encoder
  - `apps/daemon/src/ema_sqlite_helpers.erl` projection-write path uses the encoder via FFI
- **Done when:**
  - Single trait/module owns projection encode for all 30+ projections
  - No JSON serialization splits between Gleam/Erlang/Elixir for the same shape
- **Depends on:** LD1

### LD4 — Schema migration spine
- **Scope:**
  - `apps/daemon/_migrations/0001_init.sql` (current schema)
  - `apps/daemon/src/ema_daemon/migrations.gleam` (apply on boot, version table)
  - `docs/architecture/25-schema-migrations.md` (new)
- **Done when:**
  - Daemon boot applies pending migrations; refuses to start on schema mismatch
  - Doc explains additive vs destructive migration policy
- **Depends on:** none (parallel to LD1–LD3)
