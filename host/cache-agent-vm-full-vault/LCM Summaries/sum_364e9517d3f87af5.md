## Page 1: "Inbox" — Shared Agent Inbox (data-page="inbox", icon: inbox)

Inspired by Front (shared inbox tool). This replaces chat as the primary interaction surface.

### Concept
Every agent output that needs human attention arrives in the Inbox. Not a feed to scroll — a queue to clear. Like email triage for agent work.

### Layout:
**Left Panel (list, 350px):**
- List of inbox items, sorted newest first
- Each item shows: agent emoji, subject line, preview text (1 line), timestamp, priority dot
- Unread items: bold, blue left-border
- Categories (filter tabs at top): All | 🔴 Urgent | 💬 Questions | ✅ Review | 📋 Proposals | 📝 Reports
- Badge count per category
- "Mark All Read" button

**Right Panel (detail):**
- Click any item → full content in right panel
- Header: agent emoji + name, subject, timestamp, mission link
- Body: full content (rendered markdown-ish: bold, code, lists)
- **Action Bar** at bottom:
  - ✅ Approve (for proposals/completions)
  - ❌ Reject (with reason field)
  - 💬 Reply (text input that sends to agent)
  - ➡️ Forward (to another agent)
  - 📌 Pin (saves to vault)
  - 🗑️ Archive
- **Reply Thread** below: shows conversation history for this item

**Keyboard shortcuts:** j/k to navigate list, enter to open, a/r/f for approve/reject/forward

### Data:
- Combine: feed events (type=question_asked, error), proposals (status=pending), task completions (needs review)
- GET /api/inbox — returns unified inbox items
- POST /api/inbox/:id/action — approve, reject, reply, forward, archive

### Seed Data:
Create 8-10 realistic inbox items mixing questions from agents, proposals needing approval, completed tasks needing review, error reports needing attention.
