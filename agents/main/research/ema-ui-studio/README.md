# EMA UI Studio

Purpose: create a high-quality, revision-friendly environment for designing the EMA operator surface.

This pack is optimized for:
- clarifying what EMA is
- generating UI mockups consistently
- reviewing iterations in Discord
- bridging research -> mockups -> implementation

Artifacts:
- `north-star.md` — what EMA is and is not
- `screen-manifest.md` — canonical surface map
- `visual-system.md` — visual language and interaction rules
- `mockup-prompts.md` — prompt pack for high-quality UI generation
- `revision-rubric.md` — how to review mockups quickly
- `discord-review-post.md` — ready-to-send review framing
