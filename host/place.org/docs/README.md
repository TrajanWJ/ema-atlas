# place.org — Documentation

This folder is the inter-session memory system. Every agent session reads this first.

## Structure
- `changelog.md` — Updated with EVERY commit. The source of truth for what happened.
- `architecture/` — System-level contracts: event bus, app registration, data model.
- `apps/` — Per-app specs: features, schema, events, status, known issues.
- `design/` — Design tokens, palette, glass tiers, animation configs.
- `decisions/` — ADRs for non-obvious architectural decisions.
- `plans/` — Phase execution plans.
