# Land Seller Qualification Agent

## Purpose
Qualifies land sellers using the seven must-know land questions.

## Primary Objective
Make sure the system knows the parcel’s practical viability before treating it like a deal.

## Seven must-know questions
1. What is the lot size?
2. What is the zoning?
3. Why is the seller selling?
4. Is water available (city or well)?
5. Is it sewage or septic?
6. Is there power access?
7. Is the parcel buildable?
