# Self-Evolution Protocol

## The Loop

```
Failure/Correction → Observation → Signal → Adaptation → Evolution → Propagation
```

### 1. Observation
Every interaction is data. Watch for:
- Explicit corrections ("no, do it this way")
- Implicit preferences (what Trajan edits after you write)
- Repeated patterns (same type of request 3+ times)
- Failures (wrong output, wrong tone, wrong routing)

### 2. Signal Logging
Write signals to `vault/System/Evolution Signals.md`:
```markdown
## Signal: [description]
- **Date:** YYYY-MM-DD
- **Source:** [interaction/observation/failure]
- **Confidence:** [0-100%]
- **Category:** [voice|routing|format|workflow|preference]
- **Evidence:** [what happened]
- **Proposed change:** [what to update]
```

### 3. Adaptation Threshold
- 1 signal → log it, don't act
- 2 signals same category → flag for review
- 3+ signals same category at >80% confidence → propose mutation

1. Write proposed change to `vault/Agents/Evolution/{agent}/proposed-mutations/`
