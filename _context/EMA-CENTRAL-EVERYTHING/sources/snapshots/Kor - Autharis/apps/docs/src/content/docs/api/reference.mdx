The Autharis public HTTP API is a standalone **Fastify 5 + TypeScript**
service (Lane F6) that lives at `services/api/`. It binds to `:4010` in
development and emits an OpenAPI 3.1 document at `/openapi.json` plus
interactive Swagger UI at `/docs`.

:::note[Source of truth]
The OpenAPI document at `http://localhost:4010/openapi.json` is authoritative.
This page mirrors the route list for discoverability — schemas live in the
OpenAPI doc.
:::

## Base URL

| Environment | URL |
| ----------- | --- |
| Development | `http://localhost:4010` |
| Swagger UI  | `http://localhost:4010/docs` |
| OpenAPI     | `http://localhost:4010/openapi.json` |

## Endpoints

The service exposes **19 endpoints** across six domain resources plus
liveness and OpenAPI introspection.

### System

| Method | Path            | Notes                      |
| ------ | --------------- | -------------------------- |
| GET    | `/healthz`      | Liveness probe             |
| GET    | `/openapi.json` | OpenAPI 3.1 document       |
| GET    | `/docs`         | Swagger UI                 |

## CORS allowlist

The API accepts cross-origin requests from exactly three origins:

- `http://localhost:3000` — autharis web (Next.js)
- `http://localhost:4321` — hub (Astro)
- `http://localhost:4000` — docs (this site)

## Sample request

```sh
curl -s http://localhost:4010/talent | jq '.[0]'
```

For a typed client, see the [SDK guide](/api/sdk/).
