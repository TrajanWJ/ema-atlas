# EMA Planes Index

## Core planes

### Canon
Target architectural truth, stable principles, and enduring product shape.

### Planning / Intention-Building
Blueprinting, shaping, design exploration, candidate intents, staged plans, and future-facing structure.

### Operational Reality
What is actually implemented and active now in the TS/Electron/services/workers runtime.

### Gap / Reconciliation
Explicit deltas between canon, planning, and implemented reality.

### Chronicle / Review / Provenance
Historical execution record, replay, review queues, annotations, promotion receipts, harvested results, and memory derivation.

## Rule
Do not collapse these planes into one blended pseudo-truth. EMA knowledge should preserve which plane a statement belongs to.
