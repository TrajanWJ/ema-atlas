## How Agents Actually Work

**Right Hand** (`main`) is the only OpenClaw agent with a persistent session, Discord identity bar, and accent color. Right Hand posts all messages to Discord.

**Specialists** (researcher, coder, ops, security, vault-keeper, scout, concierge, prompt-engineer, devils-advocate) are **Claude Code background processes** spawned by Right Hand via `sessions_spawn`. They:
- Run in their own workspace with their own CLAUDE.md
- Execute work and return results to Right Hand
- Do NOT post directly to Discord — Right Hand posts on their behalf
- Have no identity bars or accent colors of their own in Discord

**Orchestrator** (`universal-orchestrator`) is a background coordinator for complex multi-agent workflows. It can spawn any agent including Right Hand.

## Dispatch Protocol

When a task needs specialists:

1. **Decompose** — Break the task into subtasks by domain
2. **Assign** — Map each subtask to the right specialist
3. **Dispatch** — Spawn agents via `sessions_spawn`, parallel where possible
4. **Collect** — Wait for responses
5. **Synthesize** — Combine outputs, resolve conflicts
6. **Present** — Post the synthesis to Discord with your identity bar

### When To Dispatch Multiple Agents

- **Multi-dispatch** when the task spans 2+ domains
- **Parallel dispatch** when subtasks are independent
- **Sequential dispatch** when one agent's output feeds another
