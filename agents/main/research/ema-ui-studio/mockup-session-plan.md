# EMA Mockup Session Plan

## Goal
Run a tight mockup-and-revision cycle with Discord as the review surface.

## Suggested loop
1. pick one screen
2. generate 2-4 variants using prompt pack
3. review in Discord with revision tags
4. choose a winner or merge direction
5. update prompt based on review
6. repeat

## Best order
1. Home
2. Workstreams
3. Executions
4. Tasks / My Work
5. Catalog
6. Changes

## Why this order
- Home establishes identity
- Workstreams establishes EMA’s organizing principle
- Executions establishes runtime truth
- Tasks proves responsibility loop
- Catalog anchors source-of-truth
- Changes closes control-plane loop

## Output discipline
For every round, capture:
- prompt used
- image/mockup version id
- what improved
- what still feels wrong
- next revision request
