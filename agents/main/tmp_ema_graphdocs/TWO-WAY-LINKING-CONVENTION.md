# Two-Way Linking Convention

## Rule
Every important page should both:
1. link outward to related pages
2. be linked back from at least one index, track page, object page, or decision page

## Minimum page footer/header pattern
Use sections like:
- `Type:`
- `Plane:`
- `Status:`
- `Related:`
- `Backlinks expected from:`

## Link style
Prefer relative markdown links so the folder remains navigable as a portable wiki project.

## Required backlink sources
A page should usually be linked from at least one of:
- master artifact index
- track index or track seed
- object model page
- imports index
- decision digest
- gap summary
- code-vApp notes
