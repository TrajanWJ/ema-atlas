# Process Lessons

## Main correction from 2026-04-13

Earlier cross-pollination rounds underfit EMA because the search target drifted toward:
- generic agent frameworks
- generic workflow engines
- generic local-first state systems
- generic AI shells

The corrected target is EMA as:
- executive management assistant
- human↔agent work platform
- operator cockpit
- host-reality / SSH / sudo-aware bridge
- session continuity / memory / delegation / chat-work-state sync

## Key lesson

Signal is often hiding in:
- weird operator surfaces
- flawed but concept-rich personal projects
- small primitives with strong EMA relevance

not in the biggest or most polished repos.

## Ongoing rule

Pollination should cover:
- flagship vApps
- feeds / blueprint / intentions
- operator infrastructure
- tiny productivity and micro-utility vApps
