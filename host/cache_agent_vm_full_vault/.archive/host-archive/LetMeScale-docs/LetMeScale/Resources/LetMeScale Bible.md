# 1. BRAND IDENTITY & POSITIONING

## Core Positioning
- **Tagline:** "Attention Is Leverage. We Control Leverage."
- **Hero:** "We Build Attention That Produces Direct ROI."
- **Philosophy:** "Attention compounds faster than capital — if you control distribution."
- **Audience:** Creators & operators who already make money and understand leverage
- **Not for:** Beginners, view-chasers, guarantee-seekers

## Brand Tone
- **Emotional temperature:** 2/10 — clinical precision
- **Voice:** Cold authority. Written by someone who doesn't need your business.
- **Sentence rhythm:** Short declarative → longer specific sentence
- **Power dynamic:** LetMeScale is the gatekeeper; the reader applies for access

## Two-Track Model
1. **Full ROI System** — Distribution + pipeline + conversion infrastructure (Trell, Mark Shapiro, Farid)
2. **Pure Distribution Protocol** — Clipping, volume, reach only (Daniel, Chetha's campaigns)

# 2. DESIGN SYSTEM & AESTHETIC

## Visual Identity
- **Aesthetic:** Palantir × Apple × Aston Martin — monochrome glass, surgical precision
- **Background:** #000000 (void black)
- **Accent:** #991B1B (surgical red — accent only, never primary fill)
- **Glass:** White at 2-5% opacity with backdrop-blur, 1px white/8% borders
- **Typography:** General Sans (display headlines), Outfit (body), Geist Sans (labels/data)
- **Film grain:** SVG noise overlay at 2.5% opacity

## Animation Philosophy
- **Speed:** Slower than typical. 300-700ms transitions.
- **Easing:** `[0.25, 0.1, 0.25, 1]` (smooth, slightly decelerating)
- **Triggers:** Primarily scroll-based (useInView, once: true)
- **Feel:** Inevitable, not decorative. Every motion serves comprehension.
- **Performance:** Transform and opacity only. Never animate width/height/margin.
- **Library:** Framer Motion (React). All scroll-triggered entrances use `useInView` + `motion` components.

## Landing Page Section Structure (9 sections)
1. **Hero** — Headline, sub-line, ambient background
2. **Disqualifier** — "This is not for everyone" filter
3. **What We Do** — Service pillars / system overview
4. **Why This Works** — Mechanism / philosophy proof
5. **Results** — Client proof cascade (case studies)
6. **How We Engage** — Process / onboarding steps
7. **Who This Is For** — Ideal client profile
8. **Philosophy** — Core beliefs, attention-as-leverage thesis
9. **Final CTA** — Application / next step

6. **Fog Dissolve** — `blur(40px) opacity(0)` → `blur(0) opacity(1)` — 800ms, slow ease
