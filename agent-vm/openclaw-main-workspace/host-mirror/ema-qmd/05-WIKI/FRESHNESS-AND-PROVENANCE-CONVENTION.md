# Freshness and Provenance Convention

Type: canon
Plane: canon
Status: active

## Purpose
Make every important page legible in terms of trust and recency.

## Suggested metadata fields
- Type:
- Plane:
- Status:
- Freshness:
- Provenance:
- Last meaningful update:

## Freshness values
- live
- recent
- aging
- historical
- archived
- migration-only

## Provenance values
- host-inspected
- repo-read
- cross-pollination-mined
- Discord-decision-derived
- planning-synthesis
- legacy-reference

## Rule
Planning pages without provenance are weak.
Canon pages without freshness cues become dangerous.
