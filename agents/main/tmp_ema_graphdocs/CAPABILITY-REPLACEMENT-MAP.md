# Capability Replacement Map

## Goal
EMA Desktop deliverable should become a unified native system that can absorb overlapping capability from several adjacent tools/systems.

## Capability buckets
### Graph / knowledge / relationship mapping
Replaces or subsumes:
- Graphify-like mapping
- MemPalace-like organization
- explorer/linking utilities

### Repo / code context mapping
Replaces or subsumes:
- GitNexus-like repo/context linking
- local repo/project graphing

### Project / execution support
Can complement or partially replace:
- superpowers-style assistance
- GSD-style execution support

### What EMA adds uniquely
- plane-aware truth separation
- workstream identity
- chronicle/review/provenance
- CLI↔GUI mirrored workspace
- host/runtime/session binding
- agent and human shared operational context
