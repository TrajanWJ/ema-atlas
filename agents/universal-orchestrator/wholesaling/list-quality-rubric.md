# Practical list-quality rubric for wholesaling

Score each list from 1 to 5 on every dimension. A list should usually average at least 4.0 before full outbound spend.

## 1) Geography fit
- 1: market too broad, weak buyer demand, no submarket logic
- 3: acceptable area but still generic
- 5: tight zip / neighborhood selection with proven investor demand

## 2) Property type fit
- 1: mixed property types, unclear exit
- 3: mostly usable inventory with some noise
- 5: tightly matched to actual buyer appetite

## 3) Equity quality
- 1: little room for discount and fee
- 3: mixed equity, many borderline records
- 5: strong equity foundation for wholesale spreads

## 4) Motivation strength
- 1: almost no true motivation signals
- 3: one decent signal on many records
- 5: stacked signals that imply a real reason to sell

## 5) Ownership friction
- 1: owner profile gives little reason to transact
- 3: some absentee / tenure signals
- 5: ownership pattern strongly supports outreach thesis

## 6) Contactability
- 1: poor owner data, bad skip trace prospects
- 3: workable but inconsistent
- 5: clean records likely to produce contact paths efficiently

## 7) Disposition viability
- 1: hard to imagine buyer demand or assignment path
- 3: mixed resale / rental demand
- 5: obvious downstream buyer fit in that submarket

## 8) Explainability
- 1: team cannot explain why records are present
- 3: partial logic, inconsistent tags
- 5: every lead carries clear reason codes and cohort metadata

## 9) Freshness
- 1: stale pull, no event updates
- 3: somewhat recent but not monitored
- 5: recent pull with distress refresh cadence

## 10) KPI feedback readiness
- 1: no cohort tracking, no learning loop
- 3: some campaign tracking only
- 5: outcomes can be traced back to source filters and list version

## Interpretation
- **4.5 to 5.0**: premium list, prioritize budget and fastest speed-to-lead
- **4.0 to 4.4**: good production list, run with normal QA
- **3.5 to 3.9**: test list only, limited spend
- **below 3.5**: rebuild before launch

## Fast QA questions
Before launch, ask:
1. What exact seller problem is this list betting on?
2. What combination of signals makes that problem believable?
3. Can we contact these owners efficiently?
4. If they say yes, do we have a realistic wholesale exit?
5. Can we later prove whether this filter stack worked?

## Recommended system use
Store both:
- **list-level rubric score** for campaign approval
- **lead-level motivation score** for individual prioritization

Those are related but not the same. A good system needs both.
