#### 2. AGENTS.md Duplicates SOUL.md — Dispatch Protocol vs. Behavioral Rules
AGENTS.md contains behavioral instructions (anti-rationalization, verification, [[self-learning]]) that overlap with or contradict SOUL.md's voice:
- SOUL.md says "bounded retries (3 max)" → AGENTS.md says "max 3 loops" in verification. Same rule, two places.
- SOUL.md's "[[Self-Learning]] Protocol" and AGENTS.md's "Self-Evolution" section both describe how to update prompts, with different triggers (SOUL: 3+ consistent signals → update; AGENTS: 3+ consistent signals at >80% confidence → update). The confidence threshold exists only in AGENTS.md.
- SOUL.md's "Verification Before Completion" and AGENTS.md's "Two-Stage Review" are separate verification protocols that could conflict in practice.

**Fix:** SOUL.md owns *character and behavior*. AGENTS.md owns *operations and routing*. Move all behavioral duplicates out of AGENTS.md and into SOUL.md. Add the 80% confidence threshold to SOUL.md's [[self-learning]] section. Remove AGENTS.md's behavioral fragments.

Nobody is editing symbol names in installed skills. This is pure noise that could confuse agents if they read it.

**Fix:** Delete `~/skills/CLAUDE.md` and `~/skills/AGENTS.md`. They were auto-generated by `npx gitnexus analyze` when it was likely run in the wrong directory.
