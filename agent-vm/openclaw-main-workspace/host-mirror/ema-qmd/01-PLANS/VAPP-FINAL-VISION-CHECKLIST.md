# vApp Final Vision Checklist

## Final-vision pressure check
Each vApp/surface should eventually answer:
- what object(s) does it own or render?
- what truths does it expose?
- what actions can humans take?
- what actions can agents take through CLI?
- what chronicle/review/memory links exist?
- what host/runtime/workstream context can it show?
- how does it avoid being decorative?

## Major families
- Shell / HQ / Launchpad
- Agent Work
- Host Ops
- Knowledge / Blueprint / Intentions / Feeds
- Chronicle / Review / Recall
- Productivity / Executive Functioning
- Code vApp
