# Agent Knowledge

Hub for knowledge artifacts auto-generated by autonomous agents during task execution. Each subfolder contains outputs from a specific agent's task runs.

## Agent Subfolders

| Agent | Purpose |
|---|---|
| [[Agent Knowledge/coder\|coder]] | Implementation notes, code improvements, technical findings |
| [[Agent Knowledge/researcher\|researcher]] | Research loop outputs, best-practice investigations |
| [[Agent Knowledge/devils-advocate\|devils-advocate]] | Red-team reviews, critique outputs |
| [[Agent Knowledge/ops\|ops]] | Operational findings, infrastructure notes |
| [[Agent Knowledge/security\|security]] | Security audit findings, vulnerability notes |

## About This Folder

These files are auto-generated by the dispatch/pipeline system. Each task run produces a knowledge capture file named by date and task summary. Files are immutable once written — they represent what an agent found at a specific point in time.

For the current agent roster, see [[Agent Roster]].
For memory architecture governing how this knowledge is used, see [[Memory Architecture]].
