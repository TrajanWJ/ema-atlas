# EMA UI Screen Manifest

## Top-level navigation
1. Home
2. My Work
3. Workstreams
4. Changes
5. Executions
6. Catalog
7. Explore
8. System

---

## 1. Home
Role:
- command center / operator launchpad

Must show:
- attention queue
- active workstreams
- executions needing review
- degraded entities
- recent errors/anomalies
- quick links into live work

Avoid:
- dashboard soup
- unrelated vanity charts

---

## 2. My Work
Role:
- the operator’s personal cockpit

Must show:
- assigned items
- needs review
- blocked
- done recently
- recurring obligations
- due/overdue

Views:
- board
- list
- later calendar/agenda

---

## 3. Workstreams
Role:
- authoritative lane for meaningful work

Must show:
- summary
- sessions/executions
- tasks
- review items
- latest activity
- ownership
- milestones / next steps later

Target detail anatomy:
- overview
- items
- executions
- timeline
- docs/context
- risks/status

---

## 4. Changes
Role:
- proposal / approval / change control surface

Must show:
- change list
- risk state
- approval state
- linked sessions/executions
- verification state
- rollback / blast radius later

Target detail anatomy:
- overview
- approvals
- execution chain
- verification
- artifacts
- activity

---

## 5. Executions
Role:
- runtime truth workbench

Must show:
- execution list
- selected execution detail
- status panel
- evidence stream
- tool activity
- recent output
- later timeline/stages/artifacts

Target layout:
- left list or canvas
- right detail/status/evidence

---

## 6. Catalog
Role:
- entity spine / source-of-truth browser

Must show:
- locations/projects
- agents
- sessions
- later hosts/channels/artifacts/policies
- status/trust/ownership

Target detail anatomy:
- overview
- health/status
- related work
- related executions
- activity

---

## 7. Explore
Role:
- query-first investigation surface

Must show later:
- filters
- search
- saved views
- compare mode
- raw evidence pivots

---

## 8. System
Role:
- platform health and host/runtime overview

Must show:
- CPU/memory/disk
- uptime
- active sessions
- recent errors
- later route into operator-home summaries
