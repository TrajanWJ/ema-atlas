# EMA Doctrine

This folder is the canonical document home for EMA inside
`EMA-CENTRAL-EVERYTHING`.

## Folder meaning

- `master/`
  - the main EMA design doctrine
- `planning/`
  - active planning, implementation prep, and transition docs
- `research/`
  - selected syntheses, donor notes, and investigation artifacts

## What belongs here

- the master EMA design doc
- the PRD-style product doc
- the technical design doc
- the graphic design / interface mentality doc
- 0.0.5 planning decisions that shape implementation

## What does not belong here

- actual runtime code
- copied donor repos
- raw archives
- experimental scratch files with no decision value

## Operating rule

If a document explains what EMA is, how it should work, what truths it owns, or
how the product should be shaped, it should land here rather than inside donor
folders or old planning roots.
