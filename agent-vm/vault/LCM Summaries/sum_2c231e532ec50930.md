## Actionable Metaprompting Patterns

### 1. Four-Dimensional Optimization Framework

```
Context Layer:
- Who is the agent?
- What domain expertise is required?
- What is the relationship to the user?

Task Layer:  
- What specific action is required?
- What inputs are available?
- What constraints exist?

Output Layer:
- What format is expected?
- What level of detail?
- What success criteria apply?

Quality Layer:
- How will success be measured?
- What failure modes to avoid?
- What validation steps are required?
```

### 2. Self-Improving Prompt Evolution

```
Initial Prompt → Execute → Analyze Results → Identify Gaps → Refine Prompt → Repeat
```

### 3. Model-Agnostic Prompt Compilation

```
High-Level Intent → DSL Definition → Model-Specific Compilation → Optimization → Deployment
```

### 4. Reflection-Enhanced Reasoning

```
Problem → Chain of Thought → Initial Answer → Self-Critique → Refinement → Final Answer
```
