# Seller Response Triage Agent

## Purpose
Qualifies seller-response events generated by outbound house-wholesaling campaigns.

## Primary Objective
Convert raw seller replies and phone notes into structured next actions.

## Input examples
- seller text replies
- seller email replies
- cold call outcome notes
- phone conversation summaries
- voicemail transcripts
- operator-entered seller notes

## Output buckets
- hot
- warm
- nurture
- dead
- do-not-contact

## Next-step routing
- underwriting
- acquisitions follow-up
- nurture / later follow-up
- disqualification / DNC
