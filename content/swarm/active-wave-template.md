# Active Wave Template

Use this as the simplest shared shape for an EMA swarm wave.

```md
# Active Wave

## Objective

- one sentence only:
- what must be more true at the end of this wave:

## Main Lane

- owner:
- lane name:
- exact scope:
- touches:
- does not touch:
- done-when:

## Support Lanes

### Support 1
- owner:
- lane:
- purpose:
- scope:
- done-when:

### Support 2
- owner:
- lane:
- purpose:
- scope:
- done-when:

### Support 3
- owner:
- lane:
- purpose:
- scope:
- done-when:

## Recovery Lane

- active: yes/no
- reason:
- owner:
- done-when:

## Current Risks

- drift risk:
- ownership risk:
- unresolved question:

## Current Handoffs

- from:
- to:
- state:
- next step:

## Stop Rules

- what should cause the wave to pause:
- what should cause a handoff:
- what should cause a lane split:
```

## Usage notes

- Keep one main lane only.
- Add support lanes only when they protect or accelerate the main lane.
- Delete empty sections instead of filling them with noise.
- If the template becomes long, the wave is probably overcomplicated.
