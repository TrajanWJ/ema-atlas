# Handoffs

Drop short markdown notes here when one lane needs another lane, the control tower, or the user to do something.

Suggested filename:

- `2026-04-22-codex-s1-to-control-tower-shell-conflict.md`

Suggested contents:

- lane and session id
- what was blocked
- exact files involved
- what action is needed
- whether the lane can continue without that answer
