# Executive Functioning Integration

## Principle
Executive-functioning features are core EMA surfaces, not decorative productivity add-ons.

## Core human-side surfaces
- Today
- Tasks
- Notes
- Journal
- Schedule
- Brain Dumps
- Responsibilities
- Time Blocking
- Focus
- Meeting Output
- Universal Inbox
- Reconnect / Follow-up
- Shutdown Ritual

## Integration requirement
These must connect into the same EMA object world as:
- intentions
- proposals
- executions
- chronicle
- memory
- feeds
- blueprint/planning nodes

## Why
If executive-functioning surfaces are detached, EMA splits into:
- a control-plane app
- and a fake personal planner

That is explicitly not the target.
