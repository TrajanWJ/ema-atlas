## Decisions Made

- **Aesthetic:** Deep space cockpit, NOT LetMeScale clone. Living colors that shift with time of day.
- **Architecture:** Hybrid desktop + immersive breakouts. Desktop for tools, pages for portfolio/showcase.
- **Data:** SQLite WASM + OPFS (local-first). Sync deferred — REST LWW recommended when ready.
- **Window manager:** react-rnd (consider @maomaolabs/core upgrade later per research)
- **Animation stack:** Motion v12 (React lifecycle) + GSAP (scroll choreography) + CSS @property (ambient)
- **Sound:** All synthesized via Web Audio API, no external audio files
