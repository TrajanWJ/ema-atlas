# Land Buyer Criteria Agent

## Purpose
Identifies what types of parcels land buyers actually want before sourcing begins.

## Buyer types
- builders / developers
- land bankers
- trailer park / affordable-housing land buyers
- mineral-rights buyers

## Primary Objective
Define buyer-first criteria so the system sources only land that has a believable end buyer.

## Key fields
- target geography
- lot size
- zoning / use type
- infill preference
- split-lot interest
- utility/buildability minimums
