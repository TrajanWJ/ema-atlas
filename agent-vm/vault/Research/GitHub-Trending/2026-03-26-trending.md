## 2. letta-ai/claude-subconscious

Background memory agent plugin for Claude Code using [[Letta]] framework.

- Asynchronous agent watches session transcripts, reads codebase, updates 8 persistent memory blocks
- Injects guidance ("whisper") before each new prompt via stdout injection
- Multi-project support, shared user preferences across projects
- `read-only` tool mode default (Read/Grep/Glob/web search only)
- Install: `/plugin marketplace add letta-ai/claude-subconscious` + LETTA_API_KEY

⚠️ Experimental — extends closed-source Claude Code. Letta positions open-source "Letta Code" as the transparent alternative.

## 3. supermemoryai/supermemory

MIT licensed memory+context engine. Claims #1 on LongMemEval, LoCoMo, ConvoMem.

- Extracts facts, handles contradictions + temporal changes, auto-forgetting
- ~50ms retrieval, namespace isolation via "projects"
- Hybrid search: RAG + personalized memory in single query
- Multi-modal: PDFs, images (OCR), video (transcription), code (AST-aware)
- Connectors: Google Drive, Gmail, Notion, OneDrive, GitHub
- MCP integration for Claude Desktop, Cursor, Windsurf
- LangChain/LangGraph/Mastra/Agno/n8n integrations
- Open-source benchmarking framework: MemoryBench
