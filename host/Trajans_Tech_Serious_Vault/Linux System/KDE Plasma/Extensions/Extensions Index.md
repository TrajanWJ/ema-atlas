# KDE Plasma Extensions

Widgets, scripts, and plugins that extend [[KDE Plasma Overview|KDE Plasma]] beyond its defaults.

## Notes

| Note | What You'll Learn |
|------|-------------------|
| [[Must-Have Widgets]] | Essential plasmoids — System Monitor, Thermal Monitor, Event Calendar, Klipper |
| [[KWin Scripts and Tiling]] | Tiling WMs (Polonium, Krohnkite), custom [[KWin]] scripts |
| [[KRunner]] | Universal launcher — built-in runners, plugins, power tips |

## Where to Get Extensions

All available from the [[Resources and Community|KDE Store]]:
- [[Must-Have Widgets|Plasma Widgets]]: [store.kde.org/browse?cat=418](https://store.kde.org/browse?cat=418)
- [[KWin Scripts and Tiling|KWin Scripts]]: [store.kde.org/browse?cat=210](https://store.kde.org/browse?cat=210)

## Installation Paths

| Type | Location |
|------|----------|
| Widgets | `~/.local/share/plasma/plasmoids/` |
| KWin Scripts | `~/.local/share/kwin/scripts/` |
| KRunner Plugins | Via System Settings |

See [[Configuration Files]] for all paths.

## Relationship to Customization

Extensions add **functionality**, while [[Customization Index|customization]] changes **appearance and behavior**:
- Install a widget ([[Must-Have Widgets]]) → place it on a panel ([[Panels and Widgets]])
- Install a tiling script ([[KWin Scripts and Tiling]]) → bind shortcuts ([[Keyboard Shortcuts]])
- Install a KRunner plugin → configure runners ([[KRunner]])
