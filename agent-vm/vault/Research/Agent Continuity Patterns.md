# Agent Continuity Patterns

Patterns for maintaining agent state across session boundaries and recoveries.

## Key Patterns
- **CONTINUE.md** — Write state before disruptive actions, resume on restart
- **Daily notes** — Persistent memory across sessions
- **Vault as memory** — Files survive, sessions don't
