## What stands out
GitNexus is highly relevant because it frames itself as the nervous system for agent context over codebases.
Strong seams visible from the repo/readme:
- local CLI + MCP path
- web UI path
- bridge mode between them
- persistent code graph/indexing
- native + WASM storage/parsing split
- code wiki / PR review / blast-radius direction

## Best steals
- same indexed repo usable from CLI agent and web explorer
- local-first persistent code graph
- bridge mode between local service and browser UI
- repo graph as operational substrate for review/wiki/analysis
- explicit code wiki generation direction

## EMA-native adaptation
- code graph should be one region of the larger EMA graph
- repo graph should link to code sessions, workstreams, reviews, and chronicle
- bridge mode should become CLI↔GUI mirrored workspace behavior
