# Top KDE Plasma Themes

Curated list of the best community themes for [[KDE Plasma Overview|KDE Plasma 6]]. All available via the KDE Store or GitHub.

## Tier 1 — Comprehensive & Polished

| Theme | Style | Includes | Notes |
|-------|-------|----------|-------|
| **Orchis** | Clean, rounded | Global + Aurorae + [[Kvantum Engine|Kvantum]] + Color Scheme + Icons | One of the most complete theme packages |
| **Klassy** | Highly customizable | Window Decorations + Global Theme | Extremely configurable titlebars — [github:paulmcauley/klassy](https://github.com/paulmcauley/klassy) |
| **Catppuccin** | Pastel dark | Color Scheme + Plasma Style + [[Kvantum Engine|Kvantum]] + Icons + Konsole | 4 flavors (Latte/Frappé/Macchiato/Mocha) — [github:catppuccin/kde](https://github.com/catppuccin/kde) |
| **Dracula** | Dark purple | Color Scheme + Plasma Style + [[Kvantum Engine|Kvantum]] | Massive cross-app ecosystem |

## Tier 2 — Beautiful & Popular

| Theme | Style | Notable For |
|-------|-------|-------------|
| **Layan** | Flat material, purple | Translucent [[Panels and Widgets|panels]], light+dark variants |
| **Sweet** | Neon gradient dark | Pairs with Candy icon theme, vibrant |
| **WhiteSur** | macOS Big Sur clone | Complete macOS aesthetic |
| **Nordic** | Nord color palette | Calm blue-gray, popular |
| **Utterly Nord** | Modern floating panels | Clean, Nordic-inspired |
| **Colloid** | Rounded, modern | Multiple color variants |
| **Fluent** | Windows 11-inspired | Familiar for Windows migrants |

## Tier 3 — Color Scheme Focused

| Theme | Style |
|-------|-------|
| **Gruvbox** | Warm retro earth tones |
| **Everforest** | Green-tinted dark, easy on eyes |

## Installation

```
System Settings → Appearance → Global Theme → Get New Global Themes
```

Or download from [store.kde.org](https://store.kde.org) (see [[Resources and Community]] for more sources) and extract to:
- Global themes: `~/.local/share/plasma/look-and-feel/`
- Color schemes (see [[Color Management]]): `~/.local/share/color-schemes/`
- [[Kvantum Engine|Kvantum]] themes: `~/.config/Kvantum/`
- Aurorae decorations: `~/.local/share/aurorae/themes/`
