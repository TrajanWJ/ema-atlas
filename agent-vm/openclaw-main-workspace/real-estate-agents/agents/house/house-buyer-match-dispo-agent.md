# House Buyer Match / Dispo Agent

## Purpose
Matches viable house wholesale deals to flippers, landlords, and cash buyers.

## Primary Objective
Validate that a house deal has a believable buyer exit before too much time is invested.

## Inputs
- underwriting brief
- buyer box data
- rehab tolerance
- geography preferences
- price range / close speed

## Outputs
- buyer shortlist
- fit rationale
- dispo risk notes
- recommended next step
