# EMA W11-W14 Roadmap

## Week 11: Knowledge Navigation

**Goal:** Make EMA's accumulated intelligence visually navigable.

### Features
- **Knowledge Graph Browser** (4d frontend + 1d backend API)
  - Force-directed graph: projects (blue), proposals (purple), executions (green), tasks (amber), vault notes (gray)
  - Click node → details panel. Cluster by project. Filter panel. Zoom/pan.
  - Semantic search highlights matching nodes via vector similarity
  - Backend: GET /api/intelligence/graph → {nodes, edges} (top 200 by recency)
- **Semantic Search Bar** (1d)
  - Global search across all entities using vector similarity
  - Results grouped by type

**Dependencies:** Superman vectors + Vectors.Index running (W9). Data needs 2+ weeks to accumulate.
**Effort:** 5 days total
**Risk:** Performance with large vaults — mitigate with 200-node cap

**Acceptance criteria:**
- Knowledge Graph renders with real entity nodes
- Click node → details panel shows entity info
- Filter toggles work per node type
- Search highlights matching nodes

## Week 12: Multi-Space Architecture

**Goal:** Support isolated workspaces (Personal / Work / Client-A).

### Features
- **Space Model** (2d backend)
  - New Space schema + CRUD
  - Add space_id to projects, tasks, proposals, executions
  - Migration: all existing data → 'default' space
  - API: GET/POST/DELETE /api/spaces
- **Space Selector UI** (2d frontend)
  - HQ top-nav space switcher (dropdown)
  - Switch space → all views repaint with space-scoped data
  - Space-scoped Dispatch Board, proposals, tasks
- **Context Injection** (1d)
  - Agent prompts include space-level constraints
  - Each space can have constraints.md / context.md

**Dependencies:** Stable schema post-W11
**Effort:** 5 days
**Risk:** High migration complexity — use soft space context (default space = existing data), never hard-delete

## Week 13: API Provider Framework + VPS Integration

**Goal:** Unify provider management, extend EMA to control remote infra.

### Features
- **API Provider Framework** (3d)
  - Extend existing adapters (claude_cli, codex_cli, ollama, openrouter) with: OpenAI GPT-4o, Google Gemini 2.0 Flash, Mistral Large
  - Unified Provider.run(prompt, opts) interface
  - Cost tracking per provider (extend CostTracker)
  - Failover: if primary fails → secondary (extend CircuitBreaker)
  - Benchmark: run same prompt on N providers, compare quality + cost + latency
- **Provider Dashboard** (1d frontend)
  - Health cards: status, success rate, avg latency, cost/1k tokens
  - Cost breakdown by provider (week/month)
  - Failover log
- **VPS Integration** (3d)
  - Ema.VPS.Client — SSH command execution via System.cmd/ssh
  - Ema.VPS.Monitor — health polling (CPU, disk, memory via SSH)
  - Deploy command: trigger deploy script on configured VPS
  - VPS config in Ema.Settings (vps_host, vps_key_path, vps_deploy_script)
  - API: GET /api/vps/health, POST /api/vps/deploy

**Effort:** 6 days
**Risk:** Provider API keys need to be obtained. VPS SSH key setup required.

## Week 14: Cross-Linking + Polish

**Goal:** Universal entity linking + production hardening.

### Features
- **Universal Cross-Links** (4d)
  - Schema: entity_links(from_type, from_id, to_type, to_id, link_type, metadata)
  - Link types: references, blocks, inspired_by, supersedes, resulted_in
  - UI: 'Related' panel on every entity detail view
  - Link creation: 'Link to...' button in detail panels
  - Knowledge Graph edges reflect cross-links
- **Audit Trail Hardening** (1d)
  - Verify all mutations captured in audit log
  - 90-day retention policy
  - Export: GET /api/audit/export → JSONL download
- **Performance Pass** (2d)
  - Profile startup time (target: daemon ready < 3s)
  - Profile Knowledge Graph render (target: < 500ms for 200 nodes)
  - Cache /api/projects/:id/context (30s TTL)
  - Paginate large list endpoints (100 items max)

**Effort:** 7 days
