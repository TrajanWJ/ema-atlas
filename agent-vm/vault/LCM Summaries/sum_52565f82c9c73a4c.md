## 1. AI Agent Frameworks (OpenClaw Competitors)

| Framework | Status | Strengths | Weaknesses | Our Edge |
|---|---|---|---|---|
| **AutoGen** | Microsoft, active | Multi-agent conversations, Python-native | Complex setup, no Discord integration | OpenClaw has Discord-native UX + personal vault |
| **CrewAI** | Popular, VC-backed | Role-based crews, easy setup | No persistent memory, no self-evolution | We have vault + self-evolution protocol |
| **LangGraph** | LangChain ecosystem | Graph-based workflows, flexible | Heavy deps, steep learning curve | Simpler dispatch model, file-based |
| **Semantic Kernel** | Microsoft, enterprise | Enterprise grade, multi-language | Over-engineered for personal use | Personal-scale, low overhead |
| **n8n + AI nodes** | Growing fast | Visual workflow builder, 400+ integrations | No deep AI reasoning | We have deeper reasoning via Claude |

### Key Gaps We Have vs AutoGen/CrewAI:
- No visual workflow builder
- No community/marketplace for agent templates
- No multi-LLM switching (Claude-only)

### Key Advantages We Have:
- Persistent vault memory across sessions
- Discord as natural command center
- Self-evolution loop (agents improve their own prompts)
- Personal-scale simplicity (no k8s needed)
