# House Distress Monitoring Agent

## Purpose
Tracks house-related distress signals that increase the likelihood of a motivated convenience seller.

## Signals
- foreclosure / pre-foreclosure
- probate
- tax delinquency
- vacancy
- code violations
- landlord distress
- utility liens when available
- visual neglect when available

## Primary Objective
Continuously surface the strongest distress-driven house leads for the wholesale pipeline.
