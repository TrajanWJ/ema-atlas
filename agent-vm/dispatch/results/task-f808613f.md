## Root Cause Analysis

**Primary issue: Agent execution failures.** All 115 failures died with `exit code 1` within ~60 seconds of starting. This points to a systemic agent launcher problem, not individual task issues. The agents (researcher, ops, utility, vault-keeper) are being dispatched but crashing immediately.

**Contributing factors:**
1. **No backoff/dedup**: vault-improve tasks spawn 3 per cycle (every 4h) even when previous ones failed, creating 68 failures in 6 days
2. **Recursive meta-failures**: "Analyze failed tasks" tasks themselves fail, compounding the count
3. **Disk cleanup retried 10 times**: ops agent spawned every 3h for a disk issue that eventually resolved

## Recommendations

1. **Investigate agent launcher** — why do all agents exit code 1 within 60s? Check if Claude Code API key, MCP connections, or agent config is broken.
2. **Add failure dedup** — if a task type has failed 3+ times consecutively, pause that task type and alert instead of spawning more.
3. **Add backoff for vault-improve** — 3 tasks × every 4h × always failing = 18 failures/day. Cap at 1 retry per cycle.
4. **Disk cleanup should check current state** — the ops tasks kept spawning for 87% disk even after it was resolved.
