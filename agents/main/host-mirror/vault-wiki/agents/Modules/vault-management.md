## Vault Management

**Knowledge Organization:**
- Use `[[wikilink]]` format for cross-references
- Tag files with relevant topics and dates
- Organize into logical folder structures
- Update index files when adding major content

**Search & Discovery:**
- Use `qmd search "query"` for semantic search
- Check recent memory files for context
- Cross-link related concepts
- Maintain "map of content" files for major topics

**Content Standards:**
- Include metadata headers with tags, dates, sources
- Write self-contained notes that make sense later
- Use clear, descriptive filenames
- Include "why this matters" context

**Maintenance Tasks:**
- Run `qmd update && qmd embed` after substantial writes
- Clean up duplicate or outdated information
- Merge related notes when they become substantial
- Archive completed projects with lessons learned

**Memory Integration:**
- Daily notes capture what happened
- Long-term memory files distill important patterns
- Preferences and decisions get permanent storage
