## What It Is

Curated collection of system prompts from mainstream LLMs, AI tools, and AI products. Provides rare insights into the internal working mechanisms, output styles, and behavioral patterns of production AI systems.

## Covered Systems

### LLMs
- **DeepSeek** - Advanced reasoning patterns
- **ChatGPT** - Conversation management and safety
- **Claude** - Constitutional AI principles  
- **Gemini** - Multimodal interaction patterns
- **Grok** - Creative and analytical balance
- **Qwen** - Multilingual capabilities

### AI Agents & Tools
- **Cursor** - Code-first development agent
- **Dia** - Conversational assistant patterns
- **Manus** - General intelligence frameworks
- **Trae** - Programming specialist architectures

## Actionable Takeaways

### System Prompt Architecture Patterns

1. **Constitutional Frameworks**
   ```
   Core Identity → Capabilities → Limitations → Safety Rules → Output Format
   ```

2. **Role Definition Structures**
   ```
   Primary Function + Secondary Capabilities + Domain Expertise + Communication Style
   ```

3. **Behavioral Guardrails**
   ```
   What to do → What to avoid → How to handle edge cases → Escalation protocols
   ```

### Key Insights for Agent Design

1. **Multi-layered Instructions**: Production systems use hierarchical prompt structures
2. **Explicit Capability Mapping**: Clear boundaries between what agents can/cannot do
3. **Context-Aware Responses**: Dynamic behavior based on user intent classification
4. **Safety-First Architecture**: Multiple safety checks embedded throughout prompts

## Applications for Our System

### Agent Personality Development
- Extract communication style patterns from successful agents
- Adapt role definition structures for specialized agents
- Implement safety frameworks suited to our use cases

### Prompt Evolution Strategy  
- Study how production systems handle prompt updates
- Learn versioning and rollback patterns

### Multi-Agent Coordination
- Extract coordination patterns between different agent types

## Specific Techniques to Implement

1. **Prompt Layering**: Separate identity, capabilities, and safety into distinct sections
2. **Output Formatting**: Consistent structure templates across all agents
3. **Context Classification**: User intent detection for dynamic responses  
4. **Error Gracefulling**: Elegant handling of edge cases and failures
