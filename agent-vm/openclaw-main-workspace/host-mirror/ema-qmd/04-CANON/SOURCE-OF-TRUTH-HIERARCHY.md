# Source of Truth Hierarchy

## Priority order
1. Active host-reconciled runtime/code truth
2. Explicit source-of-truth runtime/backend docs
3. Bootstrap corpus / convergence database for v1.1 planning and recovery work
4. Canon/semantic docs for meaning and target shape
5. Planning/blueprint/intention documents
6. Generated artifacts and scratchpads
7. Legacy/archived materials

## Key rule
Older daemon-era docs are valuable reference, but they do not override current TS/Electron/services/workers host reality.

## Bootstrap rule
The `EMA-v1.1-Next-Steps/` working folder should be treated as the first planning/recovery dataset to ingest when rebuilding EMA v1.1 context. It does not override live runtime/code truth or SQLite operational state; it bootstraps understanding, sequencing, and reconciliation.

## Another key rule
Surfaces do not own truth.
They render and control truth.
Runtime/control-plane/chronicle objects own truth.
