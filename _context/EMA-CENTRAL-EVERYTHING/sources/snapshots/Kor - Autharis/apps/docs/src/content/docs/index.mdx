## Build against Autharis

The public HTTP API lives at `services/api` (Fastify 5, OpenAPI 3.1) and is
documented in the [API reference](/api/reference/). A typed TypeScript client,
`@autharis/sdk`, wraps it for web, CLI, mobile, and desktop consumers — see the
[SDK guide](/api/sdk/).

## How this project ships

Autharis is built by a multi-agent swarm across non-overlapping lanes. If
you are joining as an agent or reviewing decisions, read the
[swarm process](/swarm/) page.
