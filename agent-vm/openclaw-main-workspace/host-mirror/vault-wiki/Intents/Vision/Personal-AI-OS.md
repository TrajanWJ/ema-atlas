# Personal AI Operating System

An autonomous thinking companion and life management system that orchestrates AI agents, tracks workflow intent, manages knowledge, and provides observability into all running processes.

## Children
- [[Ship-Core-Loop]] — End-to-end execution: brain dump → completed work
- [[Agent-Collaboration]] — Human + agent shared workspace
- [[Knowledge-System]] — Unified wiki as knowledge engine

## Current Reality
- 46 CLI commands, 20 MCP tools, 4-tab TUI dashboard
- 18 actors (1 human + 17 agents) with phase cadence
- Proposal pipeline (9 stages), execution dispatch, result harvesting
- 1,368 vault wiki pages indexed by SecondBrain
- Context assembly: hot/warm/cold tiers + reflexion lessons

- Context assembly through wiki pages instead of 6 separate sources
