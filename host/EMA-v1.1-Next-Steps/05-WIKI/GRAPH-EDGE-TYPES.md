# Graph Edge Types

Type: canon
Plane: canon
Status: active

## Purpose
Define the main relationship types that should appear repeatedly across the EMA deliverable.

## Recommended edge families
### Structural
- parent-of
- child-of
- part-of
- belongs-to-track
- listed-in-index

### Semantic
- defines
- refines
- contrasts-with
- complements
- supersedes
- derived-from

### Operational
- implemented-by
- required-for
- depends-on
- binds-to
- attaches-to
- mirrored-in
- controlled-by

### Evidence / provenance
- observed-in
- mined-from
- imported-from
- confirmed-by
- contradicted-by
- promoted-from

### Lifecycle
- planned-in
- realized-in
- blocked-by
- reviewed-in
- harvested-into
- deprecated-by

## Rule
Use the same small set of relationship verbs repeatedly. Repetition creates a legible graph.
