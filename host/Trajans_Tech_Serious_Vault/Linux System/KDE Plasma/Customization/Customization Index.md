# KDE Plasma Customization

How to make [[KDE Plasma Overview|KDE Plasma]] yours — themes, panels, shortcuts, and workflows.

## The Customization Stack

```
What you change          What controls it
─────────────────        ─────────────────
Overall look         →   Theming System (layered)
App window style     →   Kvantum Engine
Panel layout         →   Panels and Widgets
Window behavior      →   KWin Scripts and Tiling
Workspace flow       →   Virtual Desktops + Activities
Speed / efficiency   →   Keyboard Shortcuts
```

## Quick Wins

1. **Global Theme** — one-click overhaul via System Settings → Appearance
2. **Floating panels** — already default in Plasma 6, customize width/position
3. **[[Kvantum Engine]]** — adds transparency and blur to all Qt apps
4. **[[Virtual Desktops and Activities|Activities]]** — separate Work/Personal/Gaming contexts
5. **[[Keyboard Shortcuts]]** — bind [[D-Bus Scripting|D-Bus commands]] for automation
