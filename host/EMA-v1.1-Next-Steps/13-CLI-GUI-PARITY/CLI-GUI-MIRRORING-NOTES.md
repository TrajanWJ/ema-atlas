# CLI↔GUI Mirroring Notes

## Core rule
If a human can do it in GUI, an agent should be able to do the equivalent through CLI.
If an agent does it in CLI, a human should be able to inspect/manage it in GUI.

## Implication
CLI is not a side utility. It must become a real agent workspace over shared EMA objects.
GUI is the human-optimized rendering of the same truth.

## Shared truth must include
- IDs
- statuses
- transitions
- workstream identity
- chronicle events
- approvals/reviews
- host/machine/session reality
