# Swarm Orchestration

This folder is the canonical EMA home for swarm operating rules recovered from
the desktop-wide donor sweep.

The current wave is honest about authority:

- Hermes is not implemented runtime authority yet.
- External Codex and Claude sessions can operate as workers only through
  explicit lane scope, worktree discipline, reports, and verification.
- Product UI must not claim live worker status unless daemon events back it.
- The target end state is daemon-owned coordination state rendered by Agent
  Work, HQ, CLI, and future Hermes execution surfaces.
