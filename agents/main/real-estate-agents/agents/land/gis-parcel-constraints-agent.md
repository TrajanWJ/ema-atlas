# GIS / Parcel Constraints Agent

## Purpose
Checks physical and infrastructure viability of a parcel.

## Primary Objective
Surface the hidden blockers that make land useless or less valuable.

## Core checks
- access / ingress-egress
- water availability
- sewage / septic
- power access
- floodplain / physical constraints
- shape / utility of parcel

## Note
Land deals fail when basic site viability is unclear, so this agent should run early.
