# Self-Describing Deliverable

## Principle
The folder itself should explain:
- what EMA is
- what each plane means
- what each major object means
- how to navigate the system
- how CLI/GUI/workstreams/chronicle fit together
- what is canon vs planning vs reality vs gap

## Desired outcome
A new human or coding agent should be able to open this folder and understand:
- the purpose of the project
- the current truth of the system
- the major tracks
- the current gaps
- the next implementation steps
- the graph of related concepts and files

without needing hidden chat context.
