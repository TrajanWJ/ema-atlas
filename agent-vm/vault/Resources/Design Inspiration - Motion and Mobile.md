# Design Inspiration — Motion and Mobile

Three sites covering motion design inspiration, mobile app design patterns, and design system component catalogs.

---

## 1. App Motion (appmotion.design)

**Status: ⚠️ DEAD as of early 2025** — returns a Framer "Site Not Found" 404. Was hosted on Framer and has gone offline sometime between late 2024 and early 2025.

### What It Was

A curated gallery of mobile app motion/animation design examples. Focused specifically on transitions, micro-interactions, loading animations, and onboarding motion patterns in real mobile apps.

### Content (from Wayback Machine, Dec 2024 snapshot)

- **Format:** Video clips of motion patterns from real apps, tagged with animation types
- **Organization:** By app name + motion tags (e.g. "dissolve", "morph", "transition", "loading", "sheet")
- **Apps cataloged:** Dot, Asana, 222, Lapse, and others
- **Tags observed:** onboarding, dissolve, open, transition, sheet, loading, morph, character, fun, checkbox, effects, video, introduction, tour, typography, typing
- **Volume:** Appeared to be a small, curated collection — likely dozens to low hundreds of examples, not thousands
- **Pricing:** Free (no paywall visible in archived version)
- **Creator:** Unknown individual/indie project (no company info found)

### Quality Assessment

Niche and genuinely useful *when it existed* — one of the few sites that specifically captured motion/animation patterns rather than static screenshots. The loss is notable because motion design inspiration is underserved compared to static UI pattern libraries.

### Alternatives for Motion Design Inspiration

- **Mobbin** (see below) — added an Animations feature in Nov 2025, capturing screens with motion as short videos
- **UIMovement** (uimovement.com) — motion/animation focused UI gallery
- **Pageflows** (pageflows.com) — user flow recordings with full motion
- **Lookup.design** — aggregates multiple design inspiration sources
- **Dribbble** — filter by "Animation" tag for motion work (but it's concept work, not real apps)

## 2. Mobbin (mobbin.com)

### What It Is

The largest mobile and web app design reference library in the world. Expert-curated screenshots, user flows, and (as of Nov 2025) animation recordings from real production apps. Founded in 2018, now a VC-backed product company.

**URL:** https://mobbin.com
**Founded:** 2018
**Company:** Mobbin (independent company, based on careers page at careers.mobbin.com)

### Pricing Model: Freemium

| Plan | Price | Notes |
|------|-------|-------|
| **Free** | $0 | Limited browsing, basic access |
| **Pro** | $10/mo (billed yearly) | Full access: all apps/sites, flows, animations, unlimited collections, downloads, app history |
| **Team** | $12/member/mo (billed yearly) | Pro + team collections, comments, admin tools, centralized billing, SOC 2 |
| **Enterprise** | Contact sales | Advanced security, priority support, custom legal |
| **Education** | Discounted | For students/educators |

Quarterly billing available but ~33% more expensive. Cancel anytime.

### Content Organization

Mobbin organizes content across multiple dimensions:

**Primary Browse Axes:**
- **Mobile** (iOS focus, Android growing) and **Web** apps
- **Sites** (launched Aug 2025) — marketing pages, landing pages, portfolios

**Content Types:**
- **App Categories** — industry/function classification (finance, health, social, etc.)
- **Screens** — individual screen screenshots, tagged by screen type (Home, Dashboard, Wallet & Balance, Calendar, Empty State, Subscription & Paywall, etc.)
- **UI Elements** — granular component tagging (Tab Bar, Top Navigation Bar, Bottom Sheet, Avatar, Segmented Control, Floating Action Button, Search Bar, Status Dot, Carousel, Banner, Divider, Stacked List, etc.)
- **Flows** — multi-screen user journeys (Logging In, Creating Account, Onboarding, Verifying, Searching & Finding, Filtering & Sorting, Subscribing & Upgrading, Editing & Updating, Adding & Creating, Scheduling, Sharing, etc.)
- **Animations** (Nov 2025) — screens with motion captured as short videos instead of static images

**Discovery Features:**
- **Popular Collections** — community-curated themed boards (e.g. "Behavioral UX Patterns for Habit-forming Growth", "Tactile", "(Empty) State of the art", "Animation")
- **Trending** section on homepage
- **Tabs:** Latest, Most Popular, Top Rated
- **Sites sections:** Hero, Features, Pricing filters + style filters (Brutalist, Editorial, Minimal)

### Volume

Massive. Mobbin claims to be "the largest mobile app design reference website in the world." Based on the explore page structure:
- **Hundreds of apps** cataloged (iOS and web)
- **Tens of thousands of screens** (each app has dozens to hundreds of screenshots)
- **Thousands of flows** across apps
- Content updated regularly — changelog shows consistent feature + content releases

### Notable Features

- **Visual Search** (Feb 2025) — upload a screenshot from anywhere, find visually similar screens on Mobbin
- **Similar Screens** — click any screen to find related designs
- **Animations filter** (Nov 2025) — filter to only show screens with motion
- **Live Activities, Dynamic Island, and Widgets** (Sep 2025) — out-of-app iOS content
- **Copy to Figma** — Figma plugin for direct import
- **Save to Collections** — bookmark + organize favorites
- **Comments** — annotate saved screens
- **Video flows** — watch entire user journeys with transitions and micro-interactions
- **Prototype mode** — step through flows interactively with hotspots
- **Download screens** — individual or bulk
- **Glossary** — comprehensive UI component dictionary with definitions (60+ terms: Accordion, Action Sheet, Avatar, Badge, Banner, Bottom Sheet, Button, Card, Carousel, Checkbox, Chip, Color Picker, Combobox, Command Palette, Context Menu, Date Picker, Dialog, Divider, Drawer, Dropdown Menu, and many more)

### Quality Assessment

**Verdict: Genuinely excellent. The gold standard for mobile design reference.**

This is not aggregation spam. Mobbin is carefully curated with expert-quality categorization. The multi-dimensional tagging (screen type × UI elements × flow type × app) makes it uniquely powerful for finding specific patterns. The addition of animations and visual search in 2025 filled major gaps. The Figma integration makes it immediately actionable.

The free tier is limited enough to be frustrating for regular use, pushing toward the $10/mo Pro plan — but the paid product delivers real value. Widely used by professional product/design teams (Changelog references enterprise features, SOC 2 compliance).

## 3. The Component Gallery (component.gallery)

### What It Is

A free, open reference catalog of UI components drawn from real-world design systems. Created by a front-end developer to solve two practical problems: (1) not reinventing solved UI patterns, and (2) figuring out what to call things (naming conventions across design systems).

**URL:** https://component.gallery
**Creator:** Individual developer (indie project, inspired by Christopher Alexander's *A Pattern Language*, 1977)
**Pricing:** Completely free. No paywall, no accounts, no premium tier.

Each system is tagged by:

### Volume

- **60 components** cataloged
- **95 design systems** indexed
- **2,676 total examples** (component implementations across design systems)

### Notable Features

- **Filtering:** By tech stack, resource availability (GitHub/Storybook/Figma), and features (accessibility, open source, etc.)
- **Sorting** options on design systems list
- **Cross-referencing:** Each component shows implementations from multiple design systems; each design system shows which components it includes
- **Alternative names:** Each component lists all known aliases across different systems (incredibly useful for naming debates)
- **Contribute page:** Community submissions accepted
- **No account required.** No tracking, no paywall.

### Quality Assessment

**Verdict: Extremely useful, focused reference. Not flashy, but deeply practical.**

This is the opposite of aggregation spam — it's a carefully maintained, opinionated catalog by someone who clearly uses it professionally. The cross-referencing between components and design systems is the killer feature. When you're debating "should we call it a Drawer or a Sheet or a Flyout?", this site shows you what 95 real design systems decided.

The "Unmaintained" and "Accessibility issues" tags show editorial honesty — they're not just listing everything; they're flagging quality.

**Limitations:** Static catalog only (no interactive demos, no live code). Component definitions are brief. The site is a starting point for research, not a comprehensive implementation guide. Also the site looks like it may not be frequently updated (indie project limitations).

## Recommendations

- **For mobile app design reference:** Mobbin is the clear winner and industry standard. Worth the $10/mo for regular use.
- **For motion/animation patterns:** Mobbin's Animations feature (Nov 2025) partially fills the gap left by App Motion's death. Also check UIMovement and Pageflows.
- **For design system architecture:** Component Gallery is the best free starting point for understanding naming conventions and common patterns across systems.
- **For implementation details:** Go from Component Gallery → specific design system docs (most link to GitHub/Storybook).
