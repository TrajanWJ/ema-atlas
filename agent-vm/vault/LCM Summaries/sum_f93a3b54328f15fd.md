
- Top of hill = scope is clear
- Right side = "making it happen" (execution)
- Dots move based on: tasks completed / tasks total + age of mission
- Click a dot → see the mission detail

**Agent Capacity Pipeline:**
```

```

```
POST /api/pipeline/:type/:id/advance — move item to next stage
```
