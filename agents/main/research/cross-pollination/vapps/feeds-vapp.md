# Feeds vApp — Cross-Pollination Seed

## Why this vApp matters
Feeds is the discovery and signal-ingestion surface. It should become a continuous inspiration + research + system-activity intake layer.

## Relevant source seeds

### ntfy
- Attention / escalation primitive.
- Potential imports:
  - priority signals
  - lightweight push routing
  - event fan-out to humans

### coding_agent_session_search
- Session-history indexing as infrastructure.
- Potential imports:
  - searchable historical activity
  - cross-provider trace ingestion
  - relevance ranking over sessions/artifacts

### MCP Agent Mail
- Coordination events / threaded async messages.
- Potential imports:
  - inbox-style feed lanes for delegation/comms
  - threading model for work updates

## Questions to pursue

- How should cross-pollination sources feed into Feeds without becoming noise?
