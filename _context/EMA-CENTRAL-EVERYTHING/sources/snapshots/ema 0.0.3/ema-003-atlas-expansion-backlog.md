## 5. Content Rules

- Part pages remain canonical and derivative artifact routes stay beside them.
- The docs layer should show:
  - what each document feeds
  - what kind of doc it is
  - whether it is doctrine, backlog, evidence, or implementation
- The home page should derive route counts from the data model instead of hardcoding them.
- The demo should expose unresolved choices instead of pretending the product is already settled.

## 6. Surface-Specific Deliverable Pressure

- HQ / Launchpad / Virtual Desktop:
  - preserve place.org atmosphere
  - redesign for explicit org/project/space awareness
- Wiki / semantic layer:
  - preserve filesystem and vault lineage
  - redesign as agent-readable, collaboration-aware knowledge backbone
- Chat / harness surface:
  - preserve Hermes session continuity and provider seams
  - redesign as explicit harness/driver model, not a monolithic chat clone
- Threads / Server:
  - preserve OpenClaw operator feel and role-aware collaboration
  - redesign as EMA-first with Discord as transitional mirror
- Files / media:
  - preserve shared-workspace intent
  - redesign as explicit vApps rather than attachments
