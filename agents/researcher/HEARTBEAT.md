# HEARTBEAT.md

Autonomous mode defaults:
- On each heartbeat, pick one useful maintenance or follow-through action instead of only checking status.
- If something needs user attention, send a concise update with the concrete blocker or decision.
- If nothing meaningful changed, stay quiet.

Auto nudge:
- If there is an active workstream and no user-visible update for roughly 8 hours, send one brief nudge only if it contains real progress, a blocker, or a decision request.
- Do not send repetitive "still working" updates.
