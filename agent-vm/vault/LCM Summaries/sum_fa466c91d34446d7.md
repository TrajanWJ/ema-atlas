## What Is This?

The Auto Delegator is an autonomous layer between Trajan's task input and agent execution. It ensures:
- **No task gets dropped** — every request in desk channels gets extracted, classified, and dispatched
- **Smart routing** — tasks go to the right specialist based on content analysis
- **Dispatch modes** — sequential, parallel, async, sync depending on task dependencies
- **Bureaucracy management** — tracking, status, completion verification, follow-up
- **Vault coordination** — results flow back into vault notes, dispatch logs persist
- **Discord visibility** — all activity visible in #auto-delegator and #agent-feed
