# Memory Systems Deeper Notes

Type: comparison
Plane: planning
Status: active

## MemPalace insight
MemPalace's strongest idea is not merely memory retention; it is preserving raw history and making it navigable through spatial/structural organization.

## Graphiti insight
Graphiti's strongest idea is temporal validity + provenance + evolving context graph.

## Mem0 insight
Mem0's strongest idea is practical memory productization: user/session/agent layers with integration-friendly APIs.

## EMA synthesis
EMA memory should combine:
- raw trace retention where useful
- promotion/distillation into memory objects
- temporal truth windows
- provenance to episodes/events/reviews
- graph addressability
- user/session/workstream/agent scopes

## Key rule
EMA should not choose between raw memory and distilled memory. It should support both, with explicit promotion paths.
