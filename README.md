# Lineage Index Branch

This branch is the top-level map for the EMA / Hermes / place.org / OpenClaw / ClaudeForge lineage transfer repo.

## Included branch families
- `lineage-index` — branch map, inventories, source manifest
- `codebase-ema` — EMA repo snapshot (daemon/control plane/shared workspace)
- `codebase-claudeforge` — ClaudeForge / claude-remote-discord lineage snapshot
- `codebase-place-org` — place.org repo snapshot from GitHub
- `codebase-place-companion` — place-companion repo snapshot from GitHub
- `codebase-agent-os-demo` — agent-os-demo repo snapshot from GitHub
- `lineage-openclaw` — sanitized OpenClaw runtime/doc lineage
- `docs-vault-wiki` — selected vault/wiki docs around EMA/place/openclaw/orchestrator
- `docs-host-vault-context` — selected host-vault/session-log/research context
- `design-review-fresh-context` — latest app/project/org/space/product model context from user

## Core rule
EMA owns truth. Hermes owns execution. Surfaces do not own state.
