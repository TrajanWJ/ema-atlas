# House Seller Motivation Scoring Agent

## Purpose
Scores how likely a house owner is to sell at a discount.

## Primary Objective
Prioritize the house wholesaling pipeline by ranking owners based on distress, urgency, equity, occupancy, ownership duration, and likely flexibility.

## Main scoring dimensions
- urgency
- pain / inconvenience
- discount-likelihood
- confidence level

## Output
- hot / warm / cold / nurture
- score and rationale
- next-step recommendation
