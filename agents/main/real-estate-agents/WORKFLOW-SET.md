# Workflow Set

## 1. Universal intake workflow
1. Receive lead from source
2. Normalize into common schema
3. Enrich owner + property + market context
4. Score lead quality and confidence
5. Route to best-fit division
6. Create next action
7. Post summary to lane

## 2. Wholesaling workflow
1. Build off-market list
2. Detect distress and motivation indicators
3. Enrich owner/contact context
4. Score for urgency and spread potential
5. Launch outreach or queue for outreach approval
6. Triage responses
7. Fast underwrite
8. Escalate to acquisitions
9. Match to buyer list
10. Dispo and close

## 3. Buy & Hold workflow
1. Pull on-market and off-market opportunities
2. Filter by buy box
3. Underwrite rents, expenses, and debt
4. Estimate rehab/turn scope
5. Check portfolio fit
6. Escalate offer candidate
7. Track post-close stabilization

## 4. Multifamily / Commercial workflow
1. Ingest OM, T12, rent roll, and broker notes
2. Parse and structure materials
3. Underwrite current and pro forma NOI
4. Flag distress or loan maturity dynamics
5. Generate LOI recommendation
6. Track diligence checklist
7. Surface optimization opportunities

## 5. Land / Development workflow
1. Source parcel/lot/assemblage candidate
2. Evaluate zoning and entitlement posture
3. Run GIS/constraints screening
4. Compare highest-and-best-use scenarios
5. Underwrite development economics
6. Monitor planning agenda / municipality signals
7. Escalate site-control candidate

## 6. Handoff rules

### Handoff to Wholesaling when
- seller distress is dominant
- speed beats full stabilization
- investor-buyer disposition is likely

### Handoff to Rental when
- stable or stabilizable hold economics dominate
- financing and rent support hold strategy

### Handoff to Multifamily / Commercial when
- asset complexity or size requires NOI-driven underwriting

### Handoff to Land / Development when
- land value, teardown value, or entitlements dominate existing improvement value

## 7. Status model
Use consistent statuses:
- new
- normalized
- enriched
- routed
- queued
- active
- hot
- underwritten
- escalated
- won
- dead
- nurture
