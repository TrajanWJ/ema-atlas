## Task: Replace the Feed with The Stream

### What The Stream Is
One unified chronological feed of EVERYTHING happening in the system, with inline actions on every item. Not a dashboard to look at — a surface to work from. The user should be able to handle 90% of their work without leaving this page.

### Stream Item Types (each rendered differently):
1. **Agent Activity** — agent started/completed a task, wrote vault note, found insight
   - Actions: 👍 Acknowledge, 📌 Pin to vault, 💬 Reply (opens inline reply box), 🔄 Retry
2. **Proposals Needing Decision** — inline approval directly in stream
   - Actions: ✅ Approve, ❌ Reject, 📝 Edit (expands inline editor), ⏸️ Defer
   - Show: source agent, confidence bar, linked mission, one-line summary
3. **Errors/Alerts** — things that need attention
   - Actions: 🔧 Fix (dispatches to relevant agent), 🔇 Mute, 📋 Create Task
4. **Agent Questions** — agents asking for input
   - Actions: inline text reply box, suggested quick-reply buttons
5. **Task Completions** — work finished, needs verification
   - Actions: ✅ Accept, 🔄 Redo, 💬 Feedback, 📄 View Output (expands)
6. **Vault Updates** — notes created/modified
   - Actions: 👁️ Preview (inline expandable), ✏️ Edit note path, 🔗 Link to mission
7. **System Events** — service health, cron, bridge status
   - Actions: 🔧 Investigate, 🔇 Mute category

### Stream Features:
- **Inline Reply**: clicking 💬 on any item opens a text input RIGHT THERE in the stream. Submit sends to the relevant agent via POST /api/agent/message (create endpoint in bridge if needed)
- **Keyboard shortcuts**: j/k to move between items, a = approve, r = reject, d = defer, enter = expand, / = focus omnibus
- **Filter bar**: All | 🔴 Needs Action | ✅ Completed | 💬 Conversations | ⚠️ Errors
- **Priority sorting**: items needing decisions float to top, auto-sorted by urgency
- **Real-time**: poll /api/feed every 5 seconds for new items, animate new items sliding in from top
- **Collapsible detail**: click any item to expand full context (agent conversation thread, full proposal text, error stack)
- **Batch actions**: select multiple items with checkbox → batch approve/dismiss/defer

### Bridge Endpoints Needed (add to local-server.js):
```
GET /api/stream — unified feed combining: feed events, proposals, queue items, agent status, system health
POST /api/stream/:id/action — perform action on stream item (approve, reject, reply, etc.)
POST /api/agent/message — send a message/instruction to a specific agent
```

The /api/stream endpoint should combine data from existing endpoints (/api/feed, /api/proposals, /api/queue, /api/agents) into one unified stream sorted by time.
