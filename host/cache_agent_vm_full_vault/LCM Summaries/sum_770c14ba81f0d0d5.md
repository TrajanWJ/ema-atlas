### Bridge Endpoints to Add (server.js):

1. **GET /api/system/overview** — Gather:
   - Run `uptime -p` for uptime
   - Run `cat /proc/loadavg` for load
   - Run `free -m` for memory (total, used, available)
   - Run `df -h /` for disk (total, used, available, percent)
   - Run `systemctl is-active openclaw-gateway oauth-guardian agent-os-bridge` for service statuses
   - Return structured JSON

2. **GET /api/system/agents** — Read from dispatch data:
   - Active tasks from ~/dispatch/queue/*.json (group by agent)
   - Done count from ~/dispatch/done/*.json
   - Return per-agent status

3. **GET /api/system/crons** — Run `crontab -l` + parse to extract:
   - Each cron job: schedule, command description, last-modified
   - Also check systemd timers: `systemctl list-timers --no-pager`
   
4. **GET /api/system/services** — Run `systemctl list-units --type=service --state=running --no-pager --plain` filtered to relevant ones:
   - openclaw-gateway, oauth-guardian, agent-os-bridge, bridge-sync
   
5. **GET /api/system/logs?service=NAME&lines=50** — Run `journalctl -u NAME --no-pager -n LINES --output=short-iso`

6. **GET /api/system/processes** — `ps aux --sort=-%mem | head -15` for top processes
