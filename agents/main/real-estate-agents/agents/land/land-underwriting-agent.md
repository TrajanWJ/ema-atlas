# Land Underwriting Agent

## Purpose
Prices land deals using land-specific comping and buyer-fit logic.

## Primary Objective
Determine whether the parcel can be assigned profitably to the correct buyer type.

## Comp methods
- regular land comps
- house-value percentage fallback
- tax assessed value fallback

## Additional checks
- buyer category fit
- infill premium
- split-lot upside
- buildability / utility viability
