# Session Supervision / Recovery Notes

## Problem
The new EMA must regain and exceed the old build's babysitter-grade confidence.

## Needed capabilities
- active vs stalled vs completed session classification
- last meaningful assistant action
- import/resume/rebind visibility
- workstream-linked host/provider session truth
- replayable session history
- notification/escalation for stalled work

## Why this matters
Without strong session supervision, the new stack can feel less developed than the old daemon-era EMA even if architecture is better.
