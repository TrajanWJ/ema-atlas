## Build: Missions Page (Goal Tracking + Dispatch Overview)

The Missions page is the intent-driven goal tracking and task operations center. It replaces passive Discord forum tags with a real control surface.

### Vision (from vault/Architecture/Future-Frontend-Layer.md):
"Task Workspace: queue sidebar, task detail, cancel/reprioritize controls. Streaming progress. State machine with native UI."
"Aspirational System Design": Goals are structured objects with decomposition into steps, auto-dispatched to agents.

### Data Sources (read these to understand the data shapes):
- Goals: ~/dispatch/goals/*.json (archived in goals/archive/) — each has {id, description, deadline, status, steps[{id, description, agent, status, depends_on}]}
- Queue: ~/dispatch/queue/*.json — pending tasks with {id, description, agent, priority (P0-P4), created_at}
- Done: ~/dispatch/done/*.json — completed tasks
- Failed: ~/dispatch/failed/*.json
- Feed: ~/dispatch/feed.jsonl — event stream
- Schedule: ~/dispatch/schedule.json — recurring tasks
- Agent roster: AGENTS array in data.js

### Bridge Endpoints to Add (server.js):

1. **GET /api/missions/goals** — Read all goals from ~/dispatch/goals/*.json (exclude index.json)
2. **GET /api/missions/goals/archive** — Read from ~/dispatch/goals/archive/*.json
3. **GET /api/missions/queue** — Read ~/dispatch/queue/index.json or all *.json in queue/
4. **GET /api/missions/done?limit=20** — Recent completed tasks
5. **GET /api/missions/failed** — Failed tasks
6. **GET /api/missions/schedule** — Read ~/dispatch/schedule.json
7. **GET /api/missions/feed?limit=50** — Last N lines from ~/dispatch/feed.jsonl
8. **GET /api/missions/stats** — Compute: {queueDepth, doneToday, failedToday, activeGoals, completionRate}

### Frontend — Missions Page (in app2.js):

The page has THREE panels side by side:

**Left Panel — Goal Tracker:**
- List of active goals as expandable cards
- Each goal shows: description, deadline (with countdown), progress bar (% steps done)
- Expand to see steps: each step has status dot (done/active/blocked/pending), agent emoji, description
- Archived goals collapsible section at bottom
- "No active goals" empty state with explanation

**Center Panel — Operations Board:**
- Task queue: cards sorted by priority (P0 red, P1 orange, P2 yellow, P3 blue, P4 gray)
- Each card: description (truncated), agent emoji, priority badge, time since created
- Done tasks section (collapsed by default, last 10)
- Failed tasks section (collapsed, with error indicator)
- Stats bar at top: Queue: N | Done Today: N | Failed: N | Rate: N%

**Right Panel — Activity Stream:**
- Live feed from feed.jsonl
- Each entry: agent emoji, type badge, content, relative time
- Auto-scrolls, urgent items highlighted
- Filter chips: all, tasks, errors, pipelines
