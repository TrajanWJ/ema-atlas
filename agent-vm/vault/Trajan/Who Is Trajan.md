## How I Think

- Prefers dynamic, self-evolving systems over static configurations
- "Universal orchestrator" mindset — solutions should scale without config updates
- Rapid prototyping: build → test → iterate, prioritize working solutions over perfect docs
- Expects AI agents to learn and adapt from feedback, not just follow static prompts

- See [[System Architecture Philosophy]] for detailed architectural thinking

- Transparency — all agent work must be observable
- Intelligence over automation — smart routing beats mechanical rules
- Efficiency — working solutions beat perfect documentation
- Building systems that genuinely augment capability, not just automate busywork
