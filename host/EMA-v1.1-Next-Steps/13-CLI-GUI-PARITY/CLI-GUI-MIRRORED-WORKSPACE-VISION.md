# CLI↔GUI Mirrored Workspace Vision

## Vision
EMA should function as one mirrored workspace shared by:
- humans in GUI
- agents in CLI
- chat/control surfaces like Discord/OpenClaw
- host/terminal/runtime surfaces

## Core principle
The GUI must not invent a separate universe from the CLI.
The CLI must not remain a side utility disconnected from the GUI.

## Shared truth layers
- workstream identity
- intention/proposal/approval/execution lifecycle
- chronicle/replay
- review/approval
- machine/service/peer reality
- notes/plans/artifacts/memory

## Division of labor
### CLI strengths
- exact operations
- automation
- scripting
- agent-native execution
- remote/headless use

### GUI strengths
- visibility
- supervision
- graph/timeline comprehension
- planning/spatial arrangement
- approvals/review ergonomics
- executive-functioning UX

## Requirement
Anything important enough to exist in one should be visible/manageable from the other.
