# Heartbeat checklist

Top priority: make Discord self-nudge behavior real and useful.

Rules:
- Do not post just to look alive.
- If nothing materially changed, reply `HEARTBEAT_OK`.
- If there is a real blocker, stalled implementation, failed verification, or missing lane binding that needs human attention, send one concise alert to the last Discord contact.
- Prefer surfacing: (1) blocker, (2) what changed, (3) next action needed.
- If self-nudge/continuation behavior is still not truly solved, keep working on it during heartbeat turns instead of declaring success.
- Treat lane activation, lane binding, and Discord continuation/self-nudge as important pending work until verified by an actual delivered Discord heartbeat alert.
