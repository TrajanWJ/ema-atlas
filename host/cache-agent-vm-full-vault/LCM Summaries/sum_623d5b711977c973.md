## Coding Conventions (Key Rules)

Full standards: `Agent Context/Conventions/` in the vault.

**TypeScript**: strict mode, no `any` (use `unknown`), no `as` without justification, no `!`, no enums (use `as const`), `import type` for types, `satisfies` over assertions.

**React**: server components by default, `'use client'` only at leaves, composition over props drilling, controlled forms, no array index keys. State: local → lifted → context → Zustand → TanStack Query.

**Next.js App Router**: `page.tsx` for routes, co-locate route components, Zod validation in Server Actions, `revalidateTag()` over client refetch.

**Hard Limits**: functions ≤50 lines, complexity ≤8, params ≤5, files ≤800 lines, nesting ≤4, props ≤8.

**Style**: Tailwind utility-first, `cn()`/`clsx()` for conditionals, mobile-first responsive, no `@apply`.

**Testing** (70/20/10 pyramid): test behavior not implementation, test edges and errors, Vitest + React Testing Library, push tests down the pyramid.

**Git**: conventional commits (`feat|fix|refactor|docs|test|chore: description`), branches `type/description`.

**Security**: validate all inputs with Zod at boundaries, parameterized queries, no secrets in client bundles, security headers in `next.config.js`.

**Tooling**: Biome (lint+format), pnpm, Husky + lint-staged for pre-commit.
