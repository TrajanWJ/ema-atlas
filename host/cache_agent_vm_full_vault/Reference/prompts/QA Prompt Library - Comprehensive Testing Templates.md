## What It Is

A centralized, standardized collection of AI prompts designed to enhance Quality Assurance workflows. Covers manual testing, automation, and AI-assisted testing with 100+ structured prompt templates.

## Key Categories

- **Manual QA**: Test case creation, bug reporting, exploratory testing
- **Automation QA**: Selenium, Playwright, Cypress, API testing
- **AI-Assisted QA**: Test data generation, risk analysis, intelligent test selection  
- **Specialized Testing**: Security, accessibility, performance, blockchain
- **Cursor AI Roles**: Framework-specific expert personas for IDEs
