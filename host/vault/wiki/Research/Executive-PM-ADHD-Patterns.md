# Executive Management & ADHD UX Patterns

34 tools analyzed across executive AI, project management, ADHD solutions, and life OS.

## Top Tools to Watch
- **Ambient** — AI Chief of Staff, daily briefings, 10-15h/week savings
- **Motion** — Autonomous rescheduling, set-and-forget
- **Littlebird** — Screen-reading context capture, $11M raised March 2026
- **Linear** — AI dependency detection + sprint planning
- **Goblin Tools** — Task decomposition for overwhelmed brains
- **Tiimo** — Visual time awareness for ADHD
- **Focusmate** — Virtual body doubling accountability
- **Sunsama** — Structured daily planning rituals
- **HAL-OS** — Personal AI OS for Claude Code (direct competitor)

## Patterns EMA Must Implement

### Friction Reduction
- One-click capture from anywhere
- Keyboard shortcuts for power users
- No auth friction: integrate with existing tools

### ADHD-Specific UX
- Visual time awareness (countdowns, color-coded blocks)
- Decision reduction (today only, not full backlog)
- Body doubling (presence/accountability)
- Dopamine design (streaks, velocity, micro-wins)

### Executive Function Outsourcing
- Auto task extraction from comms
- Daily briefing with structured agenda
- 'What should I do now?' advisor
- Automatic follow-up tracking

### Energy-Based Scheduling
- Track energy levels (journal mood/energy)
- Route hard tasks to high-energy windows
- Protect deep work blocks

### Gentle Nudging (Not Alarm Fatigue)
- Smart nudges tied to intent + state
- Tone: supportive ('How about...?' not 'You must')
- Pull-based discovery, not push notifications
