## The Problem

1. Proposal approved → dispatch task created in ~/dispatch/queue/
2. Dispatch system picks up → moves to ~/dispatch/active/
3. Agent (Claude Code subagent) works on it
4. Results come back → posted to Discord
5. Task moves to ~/dispatch/done/ or ~/dispatch/failed/

NONE of this lifecycle is visible in the web UI. We need to fix that.
