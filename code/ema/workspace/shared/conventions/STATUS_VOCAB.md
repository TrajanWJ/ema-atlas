# Status Vocabulary

Use these statuses consistently across workspace files.

## Core statuses
- `assigned` — work allocated but not yet actively underway
- `active` — currently being worked
- `blocked` — cannot proceed without an unblock
- `done` — completed and no further work expected here
- `stale` — no longer fresh or trustworthy without review
- `archived` — intentionally moved out of active surface

## Additional context-specific statuses
### Handoffs
- `open`
- `acknowledged`
- `resolved`
- `superseded`

### Sessions
- `active`
- `idle`
- `blocked`
- `stale`
- `closing`
- `closed`
- `crashed`

### Schedule blocks / agenda
- `queued`
- `ready`
- `active`
- `paused`
- `done`
- `missed`
- `canceled`

## Rule
Do not invent synonyms casually (`in-progress`, `working`, `busy`, `finished`, etc.) when one of the above fits.
