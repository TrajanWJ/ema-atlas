# Trajan — Learning Profile

**Last updated:** 2026-03-16 09:45 UTC

## How Trajan Learns & Works

### Work Style
- **Builder mentality** — prefers creating systems over using existing ones
- **Stream-of-consciousness typing** — fast, lots of typos, intent over form
- **Rapid iteration** — changes direction fast, expects system to keep up
- **Nocturnal sessions** — often works late (4AM EST), expects overnight progress

### Feedback Style
- **Direct corrections** — "This should be X" not "I think maybe we could consider X"
- **Immediate implementation expected** — changes should be live within the response
- **Low tolerance for delay** — notices slow responses, frustrated by silence
- **Rarely repeats** — if he has to say it twice, something failed

### Decision Making
- **Fast, intuitive** — decides quickly, course-corrects later
- **Prefers options → pick** — show 2-3 choices, he picks fast
- **High-level direction** — wants results not process details
- **"Just do it"** — hates being asked for permission on safe operations

### Learning Preferences
- **Learns by building** — not by reading docs
- **Values concrete > abstract** — show working code, not architecture diagrams
- **Impatient with theory** — wants to see things work
- **Appreciates depth when relevant** — "think hard" means actually think, don't give surface-level
