# Blueprint Planner Read Models

Status: draft architecture aid
Date: 2026-04-13

## Suggested tabs / views

### Questions
- GAC queue
- blockers
- answered/deferred history

### Aspirations
- aspiration inbox
- aspiration-to-candidate conversion
- linked planning signals

### Planning Graph
- candidate intents
- planning nodes
- canon targets
- runtime intents (visibly distinct)
- gap overlays

### Gaps
- open contradictions
- canon-reality drift
- planning-reality drift
- promotion blockers

### Promotion Queue
- canon candidates
- operational planning handoff candidates
- proposal generation candidates

### Reviewed Inputs
- reviewed Chronicle-derived candidates relevant to planning
- grouped by candidate kind and confidence

## Important rule

These are read models over multiple planes.
They should not imply one flattened storage schema.
