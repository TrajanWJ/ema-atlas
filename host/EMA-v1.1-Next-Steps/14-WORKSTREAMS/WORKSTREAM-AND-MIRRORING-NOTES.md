# Workstream and Mirroring Notes

## Key requirement
One workstream should remain the same entity across:
- GUI
- CLI
- Discord/chat
- terminal/live view
- chronicle/replay
- review/approval surfaces

## Why this matters
Lack of durable workstream identity is one of the easiest ways EMA fractures into parallel universes.

## Immediate requirement for v1.1
Define a single workstream/session/thread identity model and make it authoritative across all surfaces.
